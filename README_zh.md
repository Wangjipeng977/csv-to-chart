## 快速开始

### 安装

```bash
# 通过 ClawHub 安装
clawhub install Csv To Chart

# 或手动复制
cp -r Csv To Chart ~/.openclaw/skills/
```

### 使用方法

```bash
# 模式 1：读取
clawhub run Csv To Chart --mode read

# 模式 2：写入
clawhub run Csv To Chart --mode write --input ./data.json
```
